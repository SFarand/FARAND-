# FARAND Beauty ✿

### Beauty Inspired by Nature

FARAND Beauty is a modern and elegant beauty website featuring perfumes, skincare, and makeup products. Its design combines natural inspiration with a clean and stylish shopping experience.

## ✨ Features
- Modern and elegant design
- Featured beauty products
- Perfume and skincare categories
- Product showcase
- Responsive layout

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

## 🌿 About
FARAND Beauty brings beauty, fragrance, and elegance together through a nature-inspired digital experience.
